# 更新日志

## v1.3.0 (2026-10-03)

代码审计修复与逻辑优化，行为兼容 v1.2.0：

### 修复

- **多群推送短路 bug**：`_flush_pending` 中 `sent = sent or await ...` 短路求值，导致绑定多个群时只有第一个群实际收到推送（后续群被跳过）；现逐群发送，任一群成功即视为该条完成
- **超长微博全文被截断**：`show_full_weibo_text` 拉回的全文被 `text_max_length`（默认 100 字）二次截断，功能形同虚设；现全文使用独立安全上限（2000 字符），不再受摘要长度影响
- **转发原微博长文**：开启全文模式后，转发的原微博超长时同样通过 `/statuses/extend` 拉取全文
- **风控梯度永不重置**：`_risk_level` 只升不降，历史上偶发 3 次 432 后冷却永久固定 60 分钟；现距上次触发超过 2 小时自动重置梯度
- **冷却期内叠加升级**：同一轮请求中多次 432（主请求 + 换身份重试）会连续推高冷却梯度；现冷却期内重复触发不再叠加升级

### 改进

- **`custom_cookie` 真正生效**：此前该配置项仅有面板定义、代码从未使用；现填写后插件跳过游客身份流程（预热/续期/换新），直接用自定义 Cookie 请求接口，失效时明确报错
- **冷却期出网拦截**：风控冷却期间 `_api_get` 直接快速失败，`微博添加` 等指令触发的请求不再穿透冷却继续打到微博
- **并发加固**：请求间隔（`_pace`）与游客续期（`_renew_visitor`）加锁串行，指令处理与轮询任务并发时不再出现间隔失效、双重换新
- **待推送队列健壮性**：`state.json` 载入时校验条目结构并补默认值，超限截断；重试计数改用防御性读取
- **细节**：`_get_text` 最后一次重试后不再多余等待；账号重试判断改用实时时间（修复长轮询中过期 `now` 导致的误跳过）；`微博检测` 在已有检查进行中时明确提示；日志措辞「推送」修正为「检测到」（检测数含被过滤微博）

## v1.2.0 (2026-10-03)

参考同类优秀项目（jiantoucn/astrbot_plugin_weibo_monitor）做的功能增强，保持免 Cookie 架构不变：

- 新增 **自定义消息模板** `message_format`：支持 `{name}`/`{time}`/`{weibo}`/`{link}` 占位符与 `\n` 换行
- 新增 **屏蔽词 / 白名单关键词过滤**：正文命中屏蔽词不推送；配置白名单后仅推送命中关键词的微博
- 新增 **时效过滤** `max_post_age_minutes`：不推送过旧微博，失败重试的过期待办自动清除，保持"实时转发"语义
- 新增 **超长微博全文** `show_full_weibo_text`：通过 `/statuses/extend` 获取全文（游客身份实测可用），失败自动回退摘要
- 新增 **消息发送超时** `message_send_timeout`：防止单个平台适配器无响应卡住轮询任务；发送返回 False 视为失败并进入重试
- 拉取全文的额外请求同样纳入全局请求间隔与风控冷却体系

## v1.1.0 (2026-10-03)

基于微博对游客访问的反爬/限流调研（432 自定义风控码：游客身份过期、频率/累计量、IP 信誉三类因素叠加）做稳定性加固：

- 432/418 **全局冷却**：IP 级风控不再按账号重试，10→30→60 分钟梯度升级，成功一次即解除
- **游客身份续期节制**：复用 3 天、换新间隔 ≥10 分钟、每小时最多 3 次、失败指数退避
- **全局请求间隔闸**：任意两次微博请求强制 2~5 秒随机间隔
- **UA 与游客身份绑定**：UA 池随机选取并随身份持久化，保持指纹一致性
- **启动预热**：重启后先访问主页刷新 `_T_WM`/XSRF 指纹
- 新增可选 **proxy 配置**：海外/VPS 部署可走国内出口代理

## v1.0.0 (2026-10-03)

首个版本：

- 完全免 Cookie：自动向微博游客系统（`visitor.passport.weibo.cn`）换取并维护匿名游客身份（genvisitor/incarnate → `.weibo.cn` 域 SUB/SUBP），本机实测拉取 `ok=1`
- 轮询监控指定微博账号，新微博推送「昵称+摘要+链接」到绑定的 Q 群
- 指令：微博绑定/解绑/添加/删除/列表/检测/状态/帮助
- 基线机制防历史微博刷屏、推送失败重试、账号级指数退避、状态持久化
